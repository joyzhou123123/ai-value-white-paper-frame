# 可编辑 HTML / Editable HTML

## 使用 / Use

用户要求可编辑 HTML 或浏览器填写时，复制 `assets/editable-whitepaper-zh.html` 和 `assets/editable-whitepaper-en.html` 到交付目录（按用户明确指定的语言裁剪），不要直接修改 Skill 内的模板。两份各自是离线可打开的自包含 HTML，不需要服务器、CDN 或额外资源。When editable HTML is requested, copy the assets to the deliverable directory and populate them from the evidence; never edit the original assets in place.

用已核实的内容替换对应占位文本；无法核实的具体内容保留浅黄色与“待补充/待验证”标识。将真实来源、配置条件、可公开范围写清；缺少的 Owner 单元格保持空白、浅黄色并提供独立字段，不要把假设示例写成事实。章节按所用简版/证据型框架和用户需求裁剪或扩充；保留披露、来源和边界。

模板有“编辑正文/完成编辑”、可直接填写和新增行的 Owner 表格、“下载已编辑 HTML”“打印/保存 PDF”和“恢复原稿”。修改暂存在当前浏览器的本地存储；本地存储不可用时页面会提示下载。下载的单文件包含当前内容，但不是实时协作，也不会自动同步给其他人或替换原文件。生成和分享前应告知使用者下载保存；不自动上传内部资料。

交付前在实际浏览器验证正文编辑、Owner 字段、刷新恢复、目录跳转、下载后再次打开、中文/英文显示及浏览器控制台错误；与证据台账核对数据和限制。保留测试时使用的环境及限制，不声称浏览器本地保存等同于团队协作。公开发布前由负责人核实事实、测试记录、公开授权及黄色标记；审阅稿不是正式对外稿。


## 中英文切换与填写状态 / Bilingual switching and completion state

当用户要求单份中英文可编辑 HTML：右上角提供中英文切换，保持同一字段的双向映射；修改任一语言后将改动翻译到对应字段，保留模型名、数字、币种、单位、引用与证据条件，提供人工审校提示。不得声称仅靠静态 HTML 就能可靠实现翻译：使用实际可用的本地翻译引擎，或在用户明确知情并授权发送内容后配置远程翻译服务；翻译服务不可用、失败或未完成时保留原文并清楚显示不同步状态，不伪造翻译。仅在技术可行且经过验证时承诺自动同步；保存或下载时确保两种语言和同步状态可恢复。不要未经授权上传内部资料。

浅黄色填写格须在用户填入有效内容后自动取消黄色，清空后恢复黄色；仅空白或占位提示不算填入。已有数据待录入（例如用户定义的 Y）与缺失数据分开显示，不因颜色变化推断数据已核实。用浏览器验证中英文切换、双向编辑、失败提示、下载重开、填写/清空状态和可访问性。


## Owner 填写表与内容状态 / Owner tables and content status

- 用横向表格收集输入：每项具体内容单独成为表头，下方对应独立可编辑单元格；字段较多时按主题拆表。行业、地区、组织规模、用户和决策角色分别填写；适用时为每个细分市场指定对应 Seg PM 或用户指定的负责人。保留已有值、单位和来源，不把一组问题合进一个自由文本格。
- 缺失、需核实、已有数据待录入、已填写是不同状态。只有用户明确说明某个标记（例如 Y）的含义时才按其约定处理：如 Y 表示该行后续字段已有数据待录入，则这些字段用中性颜色并写明“已有数据，待录入”，不自动编造值；未明确覆盖的字段仍按实际状态标注。字段已填写或确认数据存在不等同于内容已经核验或获准公开，必要的主张级待核提示继续保留。
- 空白待补字段用浅黄色及文字提示，填入有效内容后去黄，清空再恢复；只含空格或占位提示不算填写。键盘可访问，下载或重新打开后保留内容及状态。模型附录按用户要求列模型名及类别；不强加产品线、状态或未经核实的分类，名称与类别有疑问时标记待确认。

## 产品名称与计算 / Product names and calculations

- 保留用户指定的完整产品名称、大小写、版本与子品牌，不擅自省略名称组成部分；中英文、图表和表头保持一致。
- 将技术指标、商业条件和可复核的计算写清，避免将不同配置或未经验证的基线直接比较。经济测算列单位、公式、输入、币种、地区、价格日期与假设；来源冲突分别列示并交由负责人核实，不自动统一口径。每次请求的 API 费用不能当作每个合格任务的总成本、实际节省或投资回报。
