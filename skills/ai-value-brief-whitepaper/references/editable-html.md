# 可编辑 HTML / Editable HTML

## 使用 / Use

用户要求可编辑 HTML 或浏览器填写时，复制 `assets/editable-whitepaper-zh.html` 和 `assets/editable-whitepaper-en.html` 到交付目录（按用户明确指定的语言裁剪），不要直接修改 Skill 内的模板。两份各自是离线可打开的自包含 HTML，不需要服务器、CDN 或额外资源。When editable HTML is requested, copy the assets to the deliverable directory and populate them from the evidence; never edit the original assets in place.

用已核实的内容替换对应占位文本；无法核实的具体内容保留浅黄色与“待补充/待验证”标识。将真实来源、配置条件、可公开范围写清；缺少的 Owner 单元格保持空白、浅黄色并提供独立字段，不要把假设示例写成事实。章节按所用简版/证据型框架和用户需求裁剪或扩充；保留披露、来源和边界。

模板有“编辑正文/完成编辑”、可直接填写和新增行的 Owner 表格、“下载已编辑 HTML”“打印/保存 PDF”和“恢复原稿”。修改暂存在当前浏览器的本地存储；本地存储不可用时页面会提示下载。下载的单文件包含当前内容，但不是实时协作，也不会自动同步给其他人或替换原文件。生成和分享前应告知使用者下载保存；不自动上传内部资料。

交付前在实际浏览器验证正文编辑、Owner 字段、刷新恢复、目录跳转、下载后再次打开、中文/英文显示及浏览器控制台错误；与证据台账核对数据和限制。保留测试时使用的环境及限制，不声称浏览器本地保存等同于团队协作。公开发布前由负责人核实事实、测试记录、公开授权及黄色标记；审阅稿不是正式对外稿。
