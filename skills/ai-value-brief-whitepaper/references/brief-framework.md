# 简版白皮书写作框架 / Bilingual brief outline

Use these headings as a flexible structure, not placeholders. Keep actual customer-facing narrative professional, detailed, and anchored to the available evidence.

1. 执行摘要 / Executive summary — 客户决策与方案价值；what the solution does and the supported takeaway.
2. 业务挑战与场景 / Business challenge and use case — 目标行业、读者、任务、现有流程及痛点；specify the user, task and existing workflow.
3. 方案与工作原理 / Solution and how it works — 产品边界、组件、架构和配置；show how the components address the task, including supported configurations.
4. 性能与价值 / Performance and value — 有条件的实测、质量、延迟、吞吐及可复核结果；state test conditions and what results mean to the customer.
5. 经济性 / Economics — 采购与运营、对照、核算周期、价格及单位、计算方法；use available actual inputs and mark missing assumptions.
6. 部署与适用边界 / Deployment and applicability — 集成、限制、适用条件和下一步验证；do not turn planning into an established capability.
7. 来源与方法 / Sources and methods — numbered traceable sources, test date, estimates, reproducibility and limitations.

黄底缺口清单 / Yellow-highlighted gap register: 优先级 Priority | 内容与字段 Field | 已有 Existing | 待补 Missing | 负责人角色 Owner role | 证据 Source | 状态 Status. In review versions yellow marks the affected content itself, not only the appendix.
