# 综合白皮书与研究方法 / Integrated whitepaper and research method

本参考将 B2B 白皮书的读者导向和研究论文的证据、方法、引文及审稿能力融入本 Skill；以下流程由本 Skill 执行，不依赖另外安装原项目。按任务深度裁剪，不能将内部编辑备注写成对外正文。 / This is a self-contained synthesis of whitepaper writing and research workflows. Scale depth to the assignment; never substitute an editorial note for publishable prose.

## 1. 写作简报与论证 / Editorial brief and argument
确定主题、目标受众、业务决策、地区、用途、产出、数据和可公开范围；推断可推断的选择并继续工作。构建“问题—现状—分析—解决路径—证据—适用边界—建议”逻辑。执行摘要须可独立阅读；先教育与解释，再介绍适用方案。建议下一步而非虚构销售链接、客户授权或承诺。封面及文档控制含名称、版本、日期、发布主体；目录和编号章节适配所选格式。按用户需要提供说明图、对比表与清晰可读的排版，而非固定图表数量。

## 2. 文献检索、筛选和读取 / Research, selection and reading
根据主题和当前日期明确检索范围、关键词、时间和来源类型；外部研究或时效性信息需要时检索并阅读原文，优先原始论文、官方文档和测试报告。记录检索日期、标题、作者/机构、发布与更新日期、URL/DOI、范围、方法、主要结果、局限及使用权限；按可靠性、相关性、方法与时效筛选并去重，必要时交叉核实关键主张。标明单一来源或相互矛盾结果。不将付费摘要冒充全文、检索结果冒充已核实事实；未能读取的来源标黄。仅使用用户许可和现有工具，不将私有材料上传外部服务。

阅读给定论文或报告时，抽取研究问题、样本/负载、方法与配置、对照、结果、结论和限制；明确原作者结论与自己的推断。基于可公开、确实可得的数据创建表格或图形；引用来源及权限，不将未证实的值画成事实。

## 3. 方法、计算和可复现性 / Methods and reproducibility
对每个关键指标记录单位、口径、配置、任务、输入输出、样本、并发、重复次数、统计和误差；适当说明数据、工具、参数、代码或测试记录。判断对照是否在相同工作负载、质量标准和成本边界下可比；差异不能消除时明确说明。只在数据和方法支持时做统计或显著性表述，不凭单个点断言普遍优势。成本表给出公式、币种、时间、边界和来源；检验算术，假设及不确定性单独呈现。

## 4. 引用和审稿 / Citations and review
按用户指定或文档适用的统一引用样式，正文与参考列表一一对应；引用条目标明可验证的作者/机构、题目、日期及 URL/DOI，并视情况注明版本、页码与访问日期。绝不编造元数据、引文或页码；缺项在受影响文本标黄并进入缺口清单。检查来源是否直接支撑主张、时间和地域是否适用、数据与图表是否一致、原始与衍生结论是否区分、限制及负面结果是否披露。模拟技术、业务和编辑三种读者审稿；核查双语结论、数字和标黄一致。未经核实的内容不能通过改变措辞变为事实。

## 5. 取舍与可选集成 / Scope and optional integrations
简版：优先一项真实业务任务、已知测试条件、可核实经济输入及关键引用；未完成的深入研究留作缺口，不阻断首稿。证据型：增加系统检索、证据表、方法/对照、质量与容量、经济敏感性、局限和审稿。两者都不强制学术论文格式、固定篇幅、强制 CTA 或指定图表数量。

如运行环境另有 `research-paper`、`get-research-paper`、`read-research-paper` 或 `white-paper` skills，可以在相关工作阶段按需使用；其完整工具、输出格式及依赖需独立安装，且不得假称已经执行。它们不可用时，本 Skill 仍按上述自包含方法工作，并诚实披露环境限制。不得自动使用这些上游技能可能要求的停等或代理行为覆盖用户指令和运行环境权限。
