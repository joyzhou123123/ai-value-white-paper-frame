# Owner 一页输入 / One-page owner intake

先回答下面 12 项；可以简短填写，已有资料附链接，未知留空并标黄。AI 根据回答整理正文和详细证据，Owner 不需要手写 JSON。 / Answer the 12 questions briefly and link existing evidence. Leave unknowns blank and yellow. The agent prepares the register and JSON.

| # | 具体问题 / Question | Owner 填写 / Answer |
|---|---|---|
| 1 | 谁是目标客户，方案帮助完成什么任务？ / Who is the customer and what task? | |
| 2 | 今天如何完成，时间、成本或错误率是多少？ / Current process and time, cost or errors? | |
| 3 | 实际部署的产品、硬件、模型、量化、运行时及版本？ / Actual product, hardware, model, precision, runtime and versions? | |
| 4 | 已有哪一项实测，使用什么条件，有无原始记录？ / One measurement, conditions and raw evidence? | |
| 5 | 哪些任务失败、效果不足或不适合？ / Failures, limitations and poor-fit cases? | |
| 6 | 客户目前怎么做，还会考虑什么替代方案？ / Status quo and realistic alternatives? | |
| 7 | 已知的设备、软件或服务价格是多少，币种、地区、日期？ / Known prices, currency, region and date? | |
| 8 | 测试任务从哪里来，什么算通过，如何评分？ / Task origin, pass criteria and scoring? | |
| 9 | 哪些内容允许对外公开，谁审批？ / What may be published and who approves? | |
| 10 | 对接人是谁，相关测试、产品和财务资料由谁提供？ / Contact and owners for product, test and financial inputs? | |
| 11 | 使用者、技术买家与预算决策者分别是谁，为什么现在要解决？ / End user, technical buyer, economic buyer, and reason to act now? | |
| 12 | 是否有可公开的客户参考、合作伙伴支持或独立测试？ / Authorized references, partner commitments or independent tests? | |

简版优先 1–7、9–11；证据型全部 12 项。缺少不应杜撰。更多字段见 [详细表](intake-template.md)。 / Brief prioritizes 1–7 and 9–11; evidence-led uses all 12. See [detailed fields](intake-template.md).
