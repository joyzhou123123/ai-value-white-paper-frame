# 通用填写模板 / Reusable intake template

为不同方案复制表格，每个字段单独填写；不存在或不适用注明原因，不编造。审阅文档的空字段、需核实字段与衍生结论标浅黄色并附文字标识。Copy for each solution; use one field per answer, record evidence and mark missing/unchecked items in pale yellow with text labels.
